# Aryabhatta Labs community

The public place to give feedback on what we've built, weigh in on what we're designing, and propose something to build together.

There is no code here. This repository exists for its **Discussions** and **Issues**.

## Where to post

| You want to | Go to |
|---|---|
| Tell us what's working or not in a product (JoeHukum, NibbleIQ, RoleGPS, Favseen) | [Product feedback form](https://github.com/AryabhattaLabs/community/issues/new?template=product-feedback.yml) |
| Suggest a feature or a new tool | [Ideas](https://github.com/AryabhattaLabs/community/discussions/categories/ideas) |
| Comment on a tool before it is released | [Design reviews](https://github.com/AryabhattaLabs/community/discussions/categories/design-reviews) |
| Propose building something with us | [Collaboration form](https://github.com/AryabhattaLabs/community/issues/new?template=collaborate.yml) |
| Ask how something works | [Q&A](https://github.com/AryabhattaLabs/community/discussions/categories/q-a) |
| Report a bug in Taught | [Taught's issue page](https://github.com/AryabhattaLabs/taught-releases/issues/new/choose) |
| Report a security problem | Privately, as described in [SECURITY](https://github.com/AryabhattaLabs/.github/blob/main/SECURITY.md) |

## Open for design review now

These tools are written up but not yet released. Each has a thread where the design is open to comment before the code is public:

- `agent-tool-result-reducer`: shrinking large tool results for LLM agents without silently losing data.
- `mcp-rest-bridge`: putting an existing authenticated REST API in front of MCP clients.
- `pytest-frozen-allowlist`: architecture rules with exception lists that can only shrink.
- `youtube-timestamped-rag`: answers from YouTube videos that link to the exact second.

## Building with us

Where someone knows a domain better than we do, we build with them. NibbleIQ is built with NutriMantra, a nutrition practice. If you know a field deeply and see a problem AI should handle better, use the collaboration form.

## Ground rules

- **This space is public.** Don't post health details, account details, API keys or anything about another person.
- **Be specific.** One concrete example helps more than a general opinion.
- **Be decent.** We remove posts that attack people.
- We are a small lab. We read everything and reply when we can. An idea being discussed is not a promise to build it.

Not on GitHub? The contact form at [aryabhattalabs.com](https://aryabhattalabs.com/#contact) reaches the same people.
